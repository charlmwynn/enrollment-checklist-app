Lasell Enrollment Webpage

# Description & Purpose
The Lasell Enrollment Webpage is a web-based application designed to help incoming students at Lasell University navigate their enrollment process smoothly. It provides a "home base" where students can:

- Track and check off enrollment steps like housing, billing, etc.
- Sign up for orientation.
- Access financial aid information.
- Find their admissions counselor and a map.

# Technologies Used
This project uses the following technologies:

- HTML & CSS – for structure and styling.
- JavaScript – for interactivity (checklist, counselor dropdown, map).
- Bootstrap – for responsive design and layout.
- Font Awesome – for icons.
- Leaflet.js / OpenStreetMap API – to display an interactive campus map.
- Google Forms Embed – for orientation registration.

# Setup & Deployment Instructions

1. Clone or download the repository:
   git clone <https://github.com/charlmwynn/enrollment-checklist-app>
2. Open the project folder.
3. Launch the application:
    Open homepage (index.html) in your preferred web browser.
    All other pages are accessible via navigation links within the site.
4. Deploy to a web server

# Overview
The enrollment webpage is meant to be a one-stop shop for enrolling Lasell University students. 

# Features & Function
    1. Homepage
        Links to each of the other enrollment webpages
    2. Enrollment checklist
        check off enrollment steps as you complete them. 
        use "check all" and "uncheck all" buttons for a quick-use of the checklist
    3. Orientation 
        fill in google form and submit your orientation registration
    4. Finances
        financial aid info and tips for lasell students
    5. Admissions
        select your home state from the drop down menu to see contact info for your assigned admissions counselor
        view a map of campus and the surrounding area
